# Metric and Reporting References

- Maier-Hein et al., *Metrics reloaded: recommendations for image analysis validation*, Nature Methods (2024): https://www.nature.com/articles/s41592-023-02151-z
- Shit et al., *clDice: a topology-preserving similarity metric for tubular structures*, CVPR (2021): https://openaccess.thecvf.com/content/CVPR2021/html/Shit_clDice_-_A_Novel_Topology-Preserving_Loss_Function_for_Tubular_Structure_CVPR_2021_paper.html
- Bland and Altman, method-comparison agreement guidance: https://www-users.york.ac.uk/~mb55/meas/ba.htm
- Maier-Hein et al., *Why rankings of biomedical image analysis competitions should be interpreted with care*, Nature Communications (2018): https://www.nature.com/articles/s41467-018-07619-7
- Community-developed checklists for publishing images and image analyses, Nature Methods (2023): https://www.nature.com/articles/s41592-023-01987-9

These references guide metric choice and reporting. They do not define a
universal numerical pass threshold for this experiment. The thresholds in
`config.json` are pre-specified project criteria and must be justified in the
paper relative to the biological endpoint and human-human agreement.
