SpaceCellCam

XIAO ESP32S3 + OV5640 AF camera firmware for fixed-period QSXGA capture, using first-shot AF, later focus reuse, sensor standby, and short Debug Mate UART status.

Current Behavior

The firmware wakes the OV5640, turns on the LED, runs AF on the first unlocked shot, then reuses the locked focus on later shots. Each capture still copies the JPEG to PSRAM, returns the frame buffer, enters sensor standby, then writes the copied JPEG to SD.
