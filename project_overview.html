Project Role

This firmware runs the XIAO ESP32S3 as a fixed-position imaging node. It turns on an LED, focuses the OV5640 module, captures a high-resolution JPEG, verifies the SD write, then waits for the next scheduled shot.

Power Rule

If the board is powered by a stable external supply, connect only TX, RX, and GND for UART logging. Avoid powering the XIAO from the PC USB port during image-capture tests if USB causes frame timeouts.
