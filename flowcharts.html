SpaceCellCam 流程圖

比較 OV5640 啟用 standby 與 sensor 維持啟用兩種拍照流程。

版本 A：啟用 Sensor Standby

flowchart TD A[拍照週期開始] --> B[Wake OV5640 from Software Standby
REG 0x3008 = 0x02] B --> C[開啟 LED] C --> D[曝光 / AF 穩定] D --> E[丟棄暫存影格] E --> F[擷取正式影格] F --> G[關閉 LED] G --> H[複製 JPEG 到 PSRAM] H --> I[歸還 camera framebuffer] I --> J[Set OV5640 to Software Standby
REG 0x3008 = 0x42] J --> K[寫入 JPEG 到 SD] K --> L[等待下一個排程週期]
重點：SD 寫入前就讓 sensor standby，降低 sensor 工作時間、發熱與暗電流風險。

版本 B：Sensor 維持啟用

flowchart TD A[拍照週期開始] --> B[開啟 LED] B --> C[曝光 / AF 穩定] C --> D[丟棄暫存影格] D --> E[擷取正式影格] E --> F[關閉 LED] F --> G[寫入 JPEG 到 SD] G --> H[等待下一個排程週期]
重點：流程較單純，較可能保留 VCM / focus 狀態，但發熱、暗電流與耗電風險較高。
